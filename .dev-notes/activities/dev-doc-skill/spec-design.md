# Design

## Current Design

**Shipped:** `.agents/skills/dev-doc/` — one-shot feature intake → `scripts/scaffold.sh` at a user path; author without reloading the skill; reinvoke for export/preview/install. Reports: Pandoc Markdown → Typst PDF. Decks: Typst + Touying PDF. Posters/cheat sheets: Typst. Report HTML via `./serve.sh` (skill) or workdir `serve-preview.sh`. DOCX/LaTeX/Docs on request (structure only; full `\documentclass` articles).

**Must not break:** thin `SKILL.md` router + aspect `references/*`; cite `@key` vs `{fig|tbl|sec:…}` in DOCX; scholarly DOCX path (filters + citeproc + section nums); scaffold assets under `assets/` matching starters; sample PDF/DOCX/TeX gitignored and regenerated by `scripts/verify.sh`; no Marp strings in the skill tree.

**Evidence:** `cd .agents/skills/dev-doc && ./scripts/verify.sh all`. Guide: `artifacts/guide-for-users.md`.

## Decisions

### DD1: Revision path
- cites: DC01, DC03, DC12
- A report is Pandoc Markdown compiled with `--pdf-engine=typst` or `-t typst`, then `typst compile`. A deck is Typst + Touying (`typst compile deck.typ`). Shared styles use `#show: apply` and Touying `config-colors`. A `.typ` report may hold layout that Markdown cannot say.

### DD2: Exports keep structure
- cites: DC01, DC19, DC21, DC07, DC22
- DOCX uses reference.docx + filters + citeproc + section numbering + Figure/Table captions + list fidelity + export-time cross-refs. Precise verify. Google Docs from that DOCX. LaTeX report/poster/cheat is a full standalone article (DC22); deck is Beamer.

### DD3: Starters and default colors
- cites: DC08, DC05, DC12
- The skill keeps four starter kinds: **Pandoc Markdown report** (plus shared Typst theme), Typst poster, Typst cheat sheet, Typst/Touying deck. A work starts with one kind. The cheat sheet is a landscape card mosaic like REF9 (Pointal). Default colors are the investor-deck navy and saffron. Cheat-sheet cards use those tokens and tints unless the document supplies more hues. A hand-written `.typ` report is the RD1 escape hatch, not the default starter.

### DD4: Skill files
- cites: DC02, DC09, DC13, DC18
- Skill folder `dev-doc`. `SKILL.md`: feature intake → scaffold at user path → side-file router. `scripts/scaffold.sh` (or equivalent) writes workdir scripts for chosen formats.

### DD5: Browser preview
- cites: DC09, DC13, DC17, DC20
- Reports: PDF page-faithful; HTML preview with assets resolving. Clear `serve.sh` entry. Port-busy messaging matches actual ports. Decks: Typst PDF only.

### DD6: Rich blocks and cross-references
- cites: DC10, DC11, DC12, DC14
- Markdown reports use `pandoc --standalone` and `#show: apply` for table grids and gray code boxes with line numbers. Table captions are the `: ` line. Figure captions are the image alt text. Bibliography uses `[@key]`. Figure/table/section pointers use Typst labels (in `.typ` or documented Markdown-safe form). Bare `@name` in Markdown is a cite, not a figure number. Deck and report diagrams are Typst vector with `fit-box`. Section numbering needs Pandoc `section-numbering`.
