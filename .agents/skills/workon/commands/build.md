# `build`

Status: `Active` (an engineering turn with no keyword: "continue", a
milestone, a fix).

Reads: policy/activity-kind.md, policy/engineering.md, policy/comments.md, policy/test-evidence.md, policy/update-cadence.md, policy/journal.md, policy/activity-md.md, policy/design-document.md

When `kind` is `thin`, do the work inline (**Activity kind**). Do not
read the launch kit or `pipelines/milestone.md`.

When `kind` is `full`, follow **Engineering while focused** and **Test
evidence**. Run each milestone through the **Milestone** pipeline;
checkpoint per **Update cadence**. Before the first sub-agent launch of
the session, read the launch kit and `pipelines/milestone.md`
(**Background sub-agents**).
