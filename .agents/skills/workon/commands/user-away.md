# `user-away`

Status: any. Session flag; it ends at the user's next message. No status
change, no journal.

Before the user leaves, request every permission the planned work needs, in
the fewest prompts (**Fewer prompts**). Replan the immediate work to reach a
clean stopping point without the user; never cross a gate. Ask nothing: take
the recommended option and note it. On return, report what is done, what is
blocked, and each assumed answer to confirm.
