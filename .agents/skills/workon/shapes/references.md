# references.md

Policy: **References**. One entry per `REF<n>`. Omit a field that does not
apply.

```markdown
# References

- REF1: <docs, specs, commits, issues, related slugs, …>
  - source: <URL, ticket ID, or `path/to/input`>
  - kept: context-only | copied (`artifacts/<name>`) | excerpt (`artifacts/<stem>-excerpt.md`)
  - fetched: <date; only for content saved from a remote source>
  - learned: <1–3 sentences>
- REF2: …
- `derived-from: <parent-slug>` — siblings only; non-load-bearing
```
