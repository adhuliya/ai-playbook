# Create sequence

1. On `full`, remind strong model. On `thin`, skip that reminder.
2. On `thin`, follow **Activity kind**. On `full`, run the **Planning
   quality bar** (includes **draft-check**; `# Scope` after the grill,
   `# Goal` from RD). Honor **Planning stages**.
3. Read each record's shape (`shapes/`, named in its policy) just before
   you write that record. Write `agent-activity.md` (`kind` as chosen,
   `stage` as chosen, default `design`; `conventions: pending`,
   `review-comments: on`, `base-branch` from the grill or `main`),
   `agent-journal.md` (`# Journal` plus a `Created` event),
   `spec-req-def.md`, `spec-design-choice.md`, `spec-design.md` (**Design
   document**), `conventions.md` (with the Setup H2), `references.md`
   (one `REF<n>` per cited item), and `notes-by-user.md` (`# Notes by
   User` only, unless the user already wrote notes). In `stage: design`,
   also write `spec-plan-outline.md` (**Plan outline**). Append one
   **Catalog** entry.
4. On `thin`, show `spec-plan-outline.md` and the Goal, then prompt
   `start-building`. When this message already contains `start-building`,
   read `commands/start-building.md` and follow it. On `full`, **File
   review** (`policy/planning-stages.md`), then the revision loop, then
   the **Execution gate**.
