# Notes files

Authoring rules for `spec-req-def.md`, `spec-design-choice.md`,
`conventions.md`, and `notes-by-user.md`. They and `references.md` exist
from birth. Shapes: `shapes/notes-files.md`.

The agent drafts all but `notes-by-user.md` best-effort from the repo and
this activity; the user reviews and corrects. Use bullets wherever
possible. What sub-agents may read or receive: `briefs/common.md`.

Each file has its own policy: `policy/requirement-def.md`,
`policy/design-choices.md`, `policy/conventions.md`,
`policy/notes-by-user.md`.
