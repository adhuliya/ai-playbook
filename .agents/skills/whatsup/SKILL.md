# Whatsup

Reply with a short session recap (~100 words or less): goal, main actions taken, current status, and open next step if any. Prefer plain sentences; skip transcripts and file dumps.

If the user asks for more detail, expand with specifics (paths, decisions, blockers) still without pasting long diffs.

Do not invent work that did not happen this session.
